# The show's sounds

Every sound here is a short cut from a recording released into the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), so none needs credit, but each is credited all the same. Each was cut from the original, its level raised or lowered so its loudest moment sits just under full scale, and re-encoded as AAC in an `.m4a` file: 96 kbit/s for stereo, 64 kbit/s for mono. `sounds.json` says how much of each file plays, how it fades in and out, how loud it plays and which volume control it follows, so the files themselves carry no fades.
